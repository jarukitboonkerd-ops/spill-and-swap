# Spill and Swap

ต้นแบบเกมตอบคำถามนิรนามผ่านเว็บมือถือ ผู้สร้างห้องเล่นด้วย คำตอบเปิดเมื่อส่งครบหรือครบ 60 วินาทีตามเซิร์ฟเวอร์ ทุกเครื่องเห็นคำตอบชุดเดียวกันในลำดับที่สุ่มไว้โดยซ่อนชื่อคนตอบ

## เล่นบน Wi-Fi เดียวกัน

ใช้ Node.js 22 ขึ้นไป แล้วรันจากโฟลเดอร์โปรเจกต์

```sh
npm ci --prefix anonymous-answers-poc
node anonymous-answers-poc/server.mjs
```

1. ให้เครื่องที่รันเซิร์ฟเวอร์และมือถืออยู่บน Wi-Fi เดียวกัน หา IP ในวง LAN ของเครื่องที่รันเซิร์ฟเวอร์ บน macOS ดูได้จาก **System Settings → Wi-Fi → Details → TCP/IP**
2. เปิด `http://<LAN-IP>:3000` บนเครื่องของโฮสต์ จากนั้นกด **สร้างห้อง** แล้วให้เพื่อนสแกน QR Code หรือคัดลอกลิงก์ส่งทางแชต
3. ให้เพื่อนกด **เข้าร่วม** พอจำนวนคนครบให้โฮสต์กด **เริ่มพื้นฐาน 5 ข้อ**
4. หลังเปิดคำตอบให้คุยกันได้ตามสบาย เมื่อพร้อมกด **พร้อมไปต่อ** กันทุกเครื่อง พอครบ 5 ข้อ โฮสต์เลือก **ความหลัง**, **Multiverse** หรือเล่นพื้นฐานซ้ำได้

สามารถตั้ง `PORT` เพื่อใช้พอร์ตอื่นได้ ห้องและคำตอบอยู่ในหน่วยความจำจนเซิร์ฟเวอร์ปิด เปิดแท็บเดิมไว้เพื่อกลับมาเล่นต่อหลังรีเฟรช

## ตรวจสอบ

```sh
node --test anonymous-answers-poc/test/*.test.mjs
```

ลองด้วยคอมและมือถือสองเครื่องได้ ให้ข้อแรกส่งครบก่อนหมดเวลา แล้วกดพร้อมเพียงเครื่องเดียวเพื่อตรวจว่าทั้งคู่ยังอยู่หน้าผลลัพธ์ ข้อถัดไปลองปล่อยหนึ่งเครื่องไม่ส่งจนหมดเวลา เมื่อเล่นพื้นฐานครบ 5 ข้อและกดพร้อมครบ ตรวจว่าปลดล็อกความหลังและ Multiverse ทั้งสองเครื่อง

## Cloudflare Workers

รันจากโฟลเดอร์ `anonymous-answers-poc`

```sh
npm ci
npx wrangler dev
```

เมื่อจะเผยแพร่ ให้ลงชื่อเข้าใช้ Cloudflare ด้วย `npx wrangler login` แล้วใช้ `npx wrangler deploy` ใช้ลิงก์ HTTPS ที่ Wrangler แสดงเพื่อสร้างห้องและ QR Code สำหรับเล่นข้ามเครือข่าย

โหมด Cloudflare เก็บสถานะของห้องใน Durable Objects แบบ SQLite และล้างข้อมูลห้องอัตโนมัติเมื่อครบ 24 ชั่วโมงหลังสร้างห้อง
